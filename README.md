# Tutor Master - EdTech Platform

A full stack EdTech platform built with React, Node.js, Express, MongoDB, AWS SQS, and Redis.

## Getting Started

### Prerequisites
- Node.js 20+
- MongoDB (local or Atlas)
- Redis (optional, falls back to in-memory)
- AWS credentials (optional, for SQS notifications)

### Backend

```bash
cd Server
npm install
npm run dev
```

### Frontend

```bash
npm install
npm start
```


## Environment Variables

Backend environment variables go in `Server/.env`. See `Server/.env` for required keys.
